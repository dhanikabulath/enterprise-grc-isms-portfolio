# ISMS Roles and Responsibilities

## Purpose

This document defines the main roles and responsibilities for operating and maintaining the Information Security Management System (ISMS) at Stark Industries Inc.

Clear responsibilities help make sure security activities are owned, carried out, and reported to the right level.

## Scope

These responsibilities apply to personnel involved in the security and operation of Stark Industries' SaaS marketing platform and the supporting systems within the ISMS scope.

## Roles and Responsibilities

### Chief Executive Officer (CEO) – Tony Stark

The CEO has overall accountability for the ISMS.

Responsibilities include:

- making sure the ISMS supports the company's strategic objectives;
- providing the resources needed to operate the ISMS;
- approving the Information Security Policy; and
- approving key ISMS decisions.

The CEO delegates day-to-day management of the ISMS to the Information Security Manager but remains accountable for it.

### Information Security Manager – Happy Hogan

The Information Security Manager leads the implementation and ongoing maintenance of the ISMS.

Responsibilities include:

- overseeing information security risk management;
- overseeing the implementation of security controls;
- coordinating audit and improvement activities;
- making sure the ISMS remains aligned with ISO/IEC 27001:2022;
- reporting ISMS performance to senior management;
- coordinating incident response; and
- coordinating internal security awareness activities.

### Cyber Security GRC Analyst – Abed Hamdan

The Cyber Security GRC Analyst supports the governance, risk, and compliance side of the ISMS.

Responsibilities include:

- managing GRC activities;
- maintaining ISMS documentation;
- maintaining policies, risk assessments, and the Statement of Applicability (SoA);
- conducting internal audits and supporting external audit activities;
- tracking corrective actions; and
- tracking compliance metrics.

### Information Security Analyst – James Rhodes

The Information Security Analyst handles day-to-day security monitoring and operational security activities.

Responsibilities include:

- monitoring security events and alerts;
- supporting threat detection;
- supporting incident handling;
- supporting vulnerability management;
- reviewing security logs; and
- monitoring endpoint security.

### IT Infrastructure Engineer – Maria Hill

The IT Infrastructure Engineer is responsible for the security of the company's supporting infrastructure.

Responsibilities include:

- managing AWS cloud infrastructure security;
- managing infrastructure access controls;
- implementing technical security controls across networks, systems, and endpoints; and
- supporting backup and recovery activities.

### Software Developer – Natalia Romanoff

The Software Developer is responsible for applying security practices during application development.

Responsibilities include:

- following secure coding practices;
- participating in the secure software development lifecycle (SSDLC); and
- addressing vulnerabilities identified through code reviews and security scans.

### All Employees and Contractors

Everyone with access to Stark Industries' systems or information has a responsibility to support information security.

Employees and contractors must:

- follow applicable information security policies and procedures;
- protect company information;
- report information security incidents;
- complete required security awareness training; and
- apply security best practices in their work.

## Authority and Escalation

The CEO delegates responsibility for the day-to-day operation of the ISMS to the Information Security Manager while retaining overall accountability.

Each role should work within its assigned responsibilities and escalate security concerns when they require a higher level of authority or decision-making.
