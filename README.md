# Stark Industries — ISO 27001 ISMS Portfolio

A practical GRC portfolio project where I built an Information Security Management System (ISMS) for **Stark Industries Inc.**, a fictional SaaS company operating in AWS.

The goal was to work through the ISO/IEC 27001:2022 process as a connected project rather than create standalone policy templates. I worked from business context and assets through risk assessment, treatment, control selection, monitoring, internal audit, and continual improvement.

> **Portfolio project:** Stark Industries Inc. is fictional. The work in this repository was completed for hands-on learning and does not represent a certified ISO 27001 implementation.

---

## What I Worked On

| Area | Work Completed |
|---|---|
| ISMS Scope | Defined organizational context, interested parties and ISMS boundaries |
| Governance | Documented security responsibilities and governance requirements |
| Asset Management | Built an asset inventory with ownership and classification |
| Risk Assessment | Defined likelihood, impact and risk-scoring criteria |
| Risk Register | Assessed asset-based threats and vulnerabilities and assigned risk owners |
| Risk Treatment | Documented treatment decisions, controls and residual risk |
| Statement of Applicability | Worked through ISO 27001:2022 Annex A applicability and justification |
| Security Policies | Developed operational policies covering key security areas |
| Monitoring | Defined security KPIs and control-evidence tracking |
| Internal Audit | Prepared an ISMS internal audit program and reporting structure |
| Management Review | Built the management-review process and records |
| Corrective Action | Created a structure for tracking nonconformities through closure |
